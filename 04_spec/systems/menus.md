# Menus, HUD and save/load screens

**Status:** membership CLOSED, 179/179 CONFIRMED; gate **not open** - 45 callees are delegated to
other subsystems (band F: `0x00404070`, `0x00405c90`, `0x0045e0f0`, `0x0048ea00`, `0x00499020`,
`0x004a5bf0`; plus input / avi / savegame seeds). Offsets and details live in the ledger row notes
(`03_re/ledger/functions.csv`); this page is a map. Tag: `CONFIRMED-BINARY` unless marked.
Widget library: `ui_widgets.md`.

## Screen stack
- `ScreenManager_GetCurrent/QueuePush/QueueReplace/QueuePop` (`0x00443140..0x004434b0`): deque of
  queued screen operations (`Deque_GrowMap`); the manager holds the current screen, not a lock.
- `Screen_Enter_*` helpers enter a fixed screen object at the named global.
- Screens: main menu (`0x00414bc0`), confirm quit, briefing, cheat code, credits, controls /
  commands dialog (binding table, all columns scroll together), options list screens, new game /
  MP new game / MP exit / net exit panels, save and load dialogs, modal message box (`0x00438350`).

## Settings accessors
`0x00407e30..0x004086b0`: control flag bits 0-3 (bit 3 also sets the camera), effects level,
object LOD, sound mute / volume / LOD, texture memory, gfx flags, CD audio, HUD type, joystick,
viewport / screen rect, display mode. Values live in the settings block around `0x004e5d10..0x004e5dcc`.

## HUD
- `Hud_InitWidgets`, `Hud_SetLayoutRects`, `Hud_ShowStandardWidgets`, `Hud_ShowMessage`,
  `Hud_ClearMessagePanels`, `HudComposite_Refresh`; layout authored for 640x480.
- Inset view: `Inset_Enable` / `Inset_Disable` write `[0x0057da2c]` (see `render.md`).
- **Scoreboard** (`0x0040e140`): >16 rows are sorted and trimmed to 16, but only **8** rows are
  shown (3 labels each); header labels use font Arial size `[+0xA0]`, weight 500; the third header
  is shown only when `[0x004f3128]` != 0.

## Save / load
- Records are 0x140 bytes (`WIN32_FIND_DATAA`-shaped), enumerated by `SaveLoadDialog_EnumerateSaves`
  and sorted **newest first** by `CompareFileTime` (`SaveRecord_IsNewer`).
- Sort = quicksort (`0x004362f0`, median-of-3 pivot) down to ranges < 17, then insertion sort.
- Vector insert grows by max(count, size); `operator new` unchecked.
- `Game_CanLoad` / `Game_CanSave` gate the menu entries.

## Known defects to reproduce
Unchecked `operator new` in record vector growth; scoreboard trims to 16 but displays 8.
