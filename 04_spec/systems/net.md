# Net - multiplayer game messages and player sync

**Scope: out of v1** (multiplayer deferred by the user on 2026-09-24). Kept specified for a later
multiplayer release. Membership CLOSED, all members CONFIRMED. Tag: `CONFIRMED-BINARY`.

## Overview
- **Game-level messages over zNetwork:** vehicle state, position events, damage and kill
  messages.
- **Network players:** respawn, the name tag, and applying remote vehicle state.
- **Single-player notes:** a few functions here are reached in single player only as no-ops or
  guards, for example `Net_ReceiveMessages` from `RecoilApp_Run` and `Net_IsSessionActive`
  checks. The remake needs just those stubs for v1.
