# zNetwork - DirectPlay transport and Zone online lobby

**Scope: out of v1** (multiplayer deferred by the user on 2026-09-24). This file keeps the
subsystem specified so that multiplayer can be picked up later without redoing the reverse
engineering. Membership CLOSED, all members CONFIRMED. Tags: `CONFIRMED-BINARY`; DirectPlay, COM
and Zone behaviour is `PLATFORM`.

## Overview
- **DirectPlay layer** (`DPlay_*`, `Net_Send*`, `NetMsgQueue_*`):
  - session enumeration, host and join, local player creation;
  - guaranteed and non-guaranteed sends: `Net_SendB_Guaranteed` uses `DPSEND_GUARANTEED`;
    `Net_SendA_NonGuaranteed` does not;
  - a message queue.
- **Zone lobby** (`Zone*`, `ZoneDlg_*`, `ZoneSink_*`, dialog 0x9a):
  - COM object CLSID `4dd3baf5-7579-11d1-b1c6-006097176556`;
  - rooms, chat, room settings;
  - launch into a DirectPlay session (`ZoneSink_OnLaunchGame`).
- **Combo and login dialogs, and helpers** (`ComboDialog_*`, `WolLoginDialog_*`, `CritSecHolder`).
