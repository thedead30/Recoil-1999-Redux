# UI widget library (`0x004b3ce0`–`0x004c0000` + vtable slots)

**Status:** gate **OPEN** — 344/344 CONFIRMED, membership CLOSED (`subsystem_registry.csv`).
Summarised from CONFIRMED ledger rows (mostly Ghidra decompiles; a few byte reads, marked in the
rows). Tag: `CONFIRMED-BINARY` unless stated. Game-side screens that use the library are in
`menus.md`. Win32 GDI / VFW / DirectInput names are `PLATFORM`.

## Base widget (vtable `0x004cca10`, 36 slots)
| offset | field |
|---|---|
| +0x04 / +0x08 | next sibling / parent (child list head/tail at +0x08/+0x0C in containers) |
| +0x0C | flags: **0x10 hidden**, 0x01 timed, 0x02 pending, 0x04 / 0x08 pending sub-states |
| +0x10 | float lifetime (timed widgets) |
| +0x14 / +0x18 | x / y |
| +0x20..+0x2C | bounds rect |

- `Widget_SetVisible` `0x00404d20`: arg 0 sets 0x10. Other code calls vtable +0x60(0/1) for this.
- `Widget_Tick` `0x004b41e0`: runs pending show/hide once; timed widgets count the **float** lifetime
  down by dt (byte-read) and hide themselves at the threshold.
- `Widget_BaseCtor` calls the dirty-flag OR **before** zeroing flags, so the OR is lost.
- `Widget_AppendChild` `0x004bc7c0`: parent child list append.
- Hit tests differ: rect test inclusive (`Widget_HitTestRect`, `TextWidget_HitTest`), list test exclusive.
- Draw dispatch: `Draw_ImageAt` `0x0048f500` → zVideo blit when the surface is current, else hook `[0x006320ac]`.

## Classes
- **ImageWidget** (`0x004d3428`): image +0x3C, owned +0x34, centred +0x48 (position is the image centre,
  integer w/2 both ways), up to 4 queued blits, global "exclusive image" `[0x0056bd1c]`.
- **Button** (`0x004d3630`, ctor `0x004b4ee0`): state images, hover/click sounds (volume 1.0), four
  vectors of caption/linked widgets. `Button_Activate` `0x004b5900` (30 callers) plays the click,
  resets input (`Input_ResetAll`), swaps image, shows/hides linked lists. Hit rect from image or rows
  (per-row alignment). Config: `Button_LoadFromConfig` `0x004b59f0`.
- **Toggle / ToggleImage / RadioGroup (≤20) / ScrollGroup (≤10 children)**.
- **Cycler**: index +0x14C clamped to [min +0x154, min(count +0x150, limit +0x158)); `Cycler_Next` wraps.
  `Cycler_SetItemImage` accepts index == limit (a 21st slot) and has no lower bound.
- **Slider**: value = (mouseX − left) / image width, **no clamp**, width 0 when no image.
- **EditField** (ctor `0x004b49e0`): 256-byte text buffer, caret (I-beam 1×10, blink 0.35), key
  command table (printable → insert; ESC/CR/BS/DEL/0x02/0x06 → handlers; signed char index). Filters:
  digits only; digits + `.-`; name chars. Resize buffer leaks the old buffer.
- **TextWidget**: 256-byte text; `TextWidget_Printf` uses **unbounded vsprintf**; bitmap font draw/measure.
- **ListLabel** (`0x004d3a88`): GDI text rendered into a 16-bit image (DrawTextA; drop shadow 0x141414;
  per-line vertical gradient by recolouring white pixels); bounded printf (256, may be unterminated);
  animated variant (blink / alternate, period 0.35). Ctor starts from a stock font; assign **leaks**
  the old font and text image.
- **ListWidget**: rows of animated labels, scrolling log (`AppendRow` shifts text up), clear range.
- **LineWidget / Caret**, **RingWidget** (shrinks radius to ≥3), **AnimImageWidget** (frame capture
  of the screen under it), **AviWidget** (VFW player; path fallback to a CD/fixed drive).
- **ScreenParticleOverlay** ×2: camera motion + fall + wind, double-buffered particles, one variant
  respawns every particle every tick (one-frame streaks); defaults 20.0 / 400.0.
- **FadeOverlay**: HW path refills a texture with colour + alpha ramp (16 entries 0..239).

## Screens
- `ScreenBase_Ctor` `0x004b9540` (15 callers): arrays of 20 images, 10 AVI widgets, 20 font presets
  (0x24 bytes), 50 labels, 10 sounds. **Vertical layout offset by display mode**: 2/4 → −40, 3/5 → 0,
  6 → +60, 7 → +144 (missing setting ⇒ 5).
- `ScreenBase_LoadFromConfig` `0x004b9900`: background capture, font presets (alignment strings
  `LEFT`/`CENTER`/`RIGHT`, unrecognised ⇒ unchanged; **preset index unchecked**), caps 20/10/50 with
  extra entries ignored. `ScreenBase_LoadConfigFile` ignores its path argument and always uses
  `Settings_OpenDetailPresetFile(0)`.
- `ScreenBase_BindWidget` binds children by name; message box uses `MB_OK`, `MB_CANCEL`, `TITLE`,
  `MESSAGE`, or builds a default 300×200 grey box.

## Known defects to reproduce (not fix)
Unbounded `vsprintf` (TextWidget_Printf); unterminated 256-char copies; label assign leaks font +
image; font handle setter leaks; edit buffer resize leaks; hover voice handle dropped without stop
(`Button_Reset`); unchecked `operator new` in loaders and list row creation; cycler 21st slot;
line-point index unchecked; list forward to current item unchecked; label field overwritten three
times in `Button_LoadStatesFromConfig` (leaks two labels); quadratic preset re-application in
`ListScreen_LoadFromConfig`.
